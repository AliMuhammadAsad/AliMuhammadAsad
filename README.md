## 🔬 Research & Publications Deck

<details open>
<summary><b>[PUB_01] Pashto Poetry Attribution using Deep Learning Techniques &mdash; IEEE Xplore</b></summary>
<br>

* **Venue:** IEEE Published &bull; [Read Paper on IEEE Xplore &rarr;](https://ieeexplore.ieee.org/document/11318475)
* **Highlights:**
  * Curated and cleaned the **first-ever dataset on Pashto poetry**, containing **35,000+ couplets across 35 poets** in an ultra-low-resource setting.
  * Engineered a specialized NLP data augmentation protocol (random deletion, random swap) that boosted feature stability.
  * Benchmark evaluation across Classical ML, Bi-LSTM, and Transformers &mdash; **Random Forest achieved 85.25% accuracy**, with Bi-LSTM closely trailing.

```
[ METRICS ] :: ACCURACY: 85.25% | CORPUS: 35,000+ COUPLETS | STATUS: IEEE PUBLISHED
```
